# GROMOS force field parameters for protein post-translational modifications

The original set of parameters was published under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) for [GROMOS 45A3 and 54A7](https:///doi.org/10.1371/journal.pcbi.1003154) parameter sets, compatible with the `GROMACS` molecular simulation package.

This repository includes the original set and extends to `GROMOS` 54A8 parameter set, including additional modifications and compatibility with `GROMOS` and `GROMACS` simulation packages.

## Usage
Refer to individual instructions for [GROMOS](ptm_parameters/GROMOS) and [GROMACS](ptm_parameters/GROMACS).

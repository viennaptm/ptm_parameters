# GROMOS force field parameters for protein post-translational modifications (GROMACS format)

Use together with the [GROMACS simulation package](https://www.gromacs.org/) 

Alternatively, to keep the GROMACS installation unchanged, create symbolic links of the folder of choice ("gromosXXXX.ff") and the file "residuetypes.dat" in the working directory when executing GROMACS programs (e.g. `pdb2gmx`).

Copy the folder of choice ("gromosXXXX.ff") and the file "residuetypes.dat" to $GMXLIB/share/gromacs/top
